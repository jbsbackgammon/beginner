# 初級戦管理（beginner）

GitHub Pagesで動作する大会成績管理ツールです。外部ライブラリ・サーバー・Google Sheets連携は不要です。

## 画面

- 結果入力：各大会の試合結果を登録、修正、削除。対戦済み組み合わせは警告（登録可能）。
- 成績管理：選手番号・氏名・よみ・出場登録。JSONバックアップの出力・取込と大会データ追加。
- ランキング表示：各大会の順位、初級戦Day1～Day3の総合順位を自動計算。
- 成績表出力：A4縦のPDF印刷、CSV出力。

## 大会ルール

| 区分 | 順位決定 | 結果入力 |
| --- | --- | --- |
| 初級戦 Day1/2/3 | 得失点差、勝越、勝率 | シングル1点、ギャモン2点、バックギャモン3点 |
| キューブ有RR | 得失点差、勝越、勝率 | 1,2,3,4,6,8,12点（4倍キューブまで） |
| 2pt RR | 勝越、勝率、試合数 | 2-0、2-1、1-1、1-2、0-2 |
| 初級戦総合 | 得失点差、勝越、勝率 | Day3出場必須／2日以上の実績・上位2日採用 |

同順位は同順位（競技順位方式）。2ptの勝率は勝／（勝＋負）とし、引き分けを除いて計算します。

初級戦総合の採用2日で得失点差が同じ場合は、旧Excelの扱いに合わせて勝越、試合数、早いDayの順に優先します。

## デプロイ

1. GitHubで公開リポジトリ `jbsbackgammon/beginner` を作成。
2. このZIPの中身をリポジトリ直下にアップロード。
3. **Settings → Pages → Build and deployment → Deploy from a branch** を選び、`main` の `/(root)` を指定。
4. `https://jbsbackgammon.github.io/beginner/` でアクセス。

Actionsワークフローは使用せず、ファイル更新が自動的にPagesへ反映される構成です。`.nojekyll` を同梱しています。

## 重要：データ保存

GitHub Pagesは静的サイトです。結果は訪問者のブラウザ `localStorage` にのみ保存されます。**他の端末とは自動同期されず、ブラウザのデータ消去時に失われます。** 1台で運用し、成績管理画面からJSONを頻繁に出力・保管してください。公開画面に入力結果を自動配信する機能もありません。全員共有・同時入力が必要なら、Google Sheets＋Apps Scriptや別のデータベースの導入が必要です。

添付Excelからの参考データは、Web公開されるリポジトリとは別の `beginner-excel-import.json` として提供します。**このJSONはGitHubにアップロードせず、必要なときだけ成績管理画面で取込してください。**
